# A-Risk Portfolio Optimizer

A Python project exploring portfolio construction, risk measurement and quantitative optimisation using Monte Carlo simulation.

The project simulates correlated returns for three assets and evaluates thousands of possible portfolios to identify portfolios with different risk and return characteristics.

## Features

* Monte Carlo simulation of asset returns
* Correlated asset returns using a correlation matrix
* Three-asset portfolio construction
* 1% portfolio-weight optimisation
* Sharpe ratio optimisation
* Minimum-volatility portfolio
* Maximum-Sharpe portfolio
* Maximum-return portfolio
* Value at Risk (VaR)
* Expected Shortfall
* Efficient frontier visualisation
* Automatic saving of the efficient-frontier plot

## Methodology

### 1. Monte Carlo simulation

The project generates 10,000 simulated return scenarios for three assets.

Returns are generated from a multivariate normal distribution so that relationships between the assets can be represented using a correlation matrix.

The simulations use a fixed random seed so that the same scenarios are used when comparing different portfolios.

### 2. Portfolio returns

For a portfolio containing three assets, the portfolio return is calculated as:

$$
R_p = w_A R_A + w_B R_B + w_C R_C
$$

where:

* \(R_p\) = portfolio return
* \(R_A, R_B, R_C\) = asset returns
* \(w_A, w_B, w_C\) = portfolio weights

The portfolio weights must satisfy:

$$
w_A + w_B + w_C = 1
$$

### 3. Portfolio optimisation

The program tests portfolio weights in 1% increments.

For every valid combination of weights, the program calculates:

* Mean return
* Volatility
* Sharpe ratio

The portfolio with the highest Sharpe ratio is identified as the maximum-Sharpe portfolio.

### 4. Sharpe ratio

The Sharpe ratio is calculated as:

$$
S = \frac{E(R_p)-R_f}{\sigma_p}
$$

where:

* \(E(R_p)\) = mean portfolio return
* \(R_f\) = risk-free rate
* \(\sigma_p\) = portfolio volatility

A higher Sharpe ratio indicates greater return relative to volatility under the assumptions of the model.

### 5. Value at Risk

The project calculates 95% Value at Risk using the simulated return distribution.

At a 95% confidence level, VaR represents the return threshold separating the worst 5% of simulated outcomes from the remaining outcomes.

### 6. Expected Shortfall

Expected Shortfall goes beyond VaR by calculating the average return among the simulated outcomes worse than the VaR threshold.

This provides information about the severity of losses in the lower tail of the simulated distribution.

### 7. Efficient frontier

The project evaluates the risk and return characteristics of all valid portfolios.

The efficient frontier represents portfolios offering the highest available return for a given level of volatility.

The graph also identifies:

* Minimum-volatility portfolio
* Maximum-Sharpe portfolio
* Maximum-return portfolio

## Current Model Assumptions

The current version is designed as an educational quantitative-finance project rather than a production investment model.

The simulation currently uses:

* Three assets
* 10,000 simulated scenarios
* Normally distributed random shocks
* Fixed expected returns
* Fixed volatilities
* A specified correlation matrix
* No transaction costs
* No short selling
* A risk-free rate of 0 for the Sharpe-ratio calculation
* Portfolio weights restricted to non-negative values

The results therefore depend heavily on the assumptions used to generate the simulated returns.

## Installation

Clone the repository:

```bash
git clone https://github.com/BeefyNomNom/A-risk-portfolio-optimizer.git
```

Move into the project directory:

```bash
cd A-risk-portfolio-optimizer
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Running the Project

Run the main portfolio program with:

```bash
python src/portfolio.py
```

The program will:

1. Generate simulated asset returns.
2. Test thousands of possible portfolio allocations.
3. Calculate portfolio return, volatility and Sharpe ratio.
4. Identify the key portfolios.
5. Calculate VaR and Expected Shortfall.
6. Generate the efficient-frontier plot.
7. Save the plot to:

```text
results/figures/efficient_frontier.png
```
